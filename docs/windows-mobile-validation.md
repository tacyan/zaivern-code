# Windows スマホ接続の修正と検証

対象: `fix/windows-update`、基点 `d78defa`、Windows x64、2026-09-11。

## 変更

- スマホリモートのウィンドウ内で縦スクロールできるようにした。表示領域の80%を高さの目安・上限とし、中央配置でも末尾へ移動できる。
- 未導入時にも Tailscale の状態と公式ダウンロード先を表示する。
- Windows / macOS 共通の「HTTPS でスマホに接続」を主操作にした。既存の HTTP 接続は詳細に移した。
- HTTPS は既存の `tailscale serve --bg --https=443 http://127.0.0.1:<port>` を使い、準備成功後に HTTPS URL / QR を表示する。Funnel は使わない。
- Windows にセキュリティ製品へのアプリ登録案内、実行中の exe パスのコピー、保存先を Explorer で開く操作を追加した。Norton の公式手順へリンクする。
- 新規9キーを同梱6言語へ追加した。
- HTTPS 準備中の接続切替では停止要求を保留し、後着の HTTPS 完了を別の接続方式に反映しない。終了時は準備処理の完了後に解除する。

## 検証

- egui の実入力イベントによるホイール試験: 456×280 / 456×800 / 1920×1050。画面内に収まり、末尾の操作まで移動できた。
- Windows ネイティブで Tailscale の既存13試験、ファイアウォール41試験が成功。
- 追加の寿命管理3試験を、同じ製品コードから抽出した一度限りの Rust ハーネスでも確認した。外部 Tailscale コマンドは実行すると失敗するスタブへ置換し、ユーザーの VPN 設定を変更しない。
- 上記ハーネスは通常3件成功。終了処理から worker の join を削除した故障版は、終了競合テストが失敗した。
- 別エージェントによる反証レビューで準備中の終了・接続切替の2競合を発見し、修正後の再レビューで解消を確認した。

## 実環境と未確認事項

- この PC では Norton 360 を検出した。開始時点では Tailscale の実行ファイル・サービスが無かった。
- 公式配布元を確認し、winget の Tailscale 1.102.3 インストーラーを取得、ハッシュ検証に成功。統合検証時にインストールも完了し、現在は `NeedsLogin`。ログインはユーザー操作が必要。
- スマホからの実 HTTPS 接続、音声入力、Norton の許可設定後の疎通、GUI の目視確認は未確認。
- Norton の独自設定をプログラムで変更していない。スタートメニューへの登録と、Norton のファイアウォールでの許可は別の操作である。
- Windows 以外の実 OS での動作は未確認。
- 既存実装には固定443番の Serve 設定に対する他アプリとの所有調停が無い。既存の Serve を使う PC での併用保証は未確認で、この変更では解決していない。
- 終了待ちは既存の CLI / 証明書取得の時限に依存する。通常UIの処理は非同期。
